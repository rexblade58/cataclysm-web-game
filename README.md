# Cataclysm Web Game

A browser-based post-apocalyptic survival game built with vanilla JavaScript and HTML5 Canvas.

## Gameplay
- Explore a procedurally generated wasteland
- Collect resources (wood, stone, food, water)
- Avoid hostile enemies
- Survive as many days as possible

## Quick Start

`ash
npm run dev
` 

Open http://localhost:8080

## Controls
- Arrow Keys / WASD: Move
